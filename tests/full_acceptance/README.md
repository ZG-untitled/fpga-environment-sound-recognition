# Stage 39 整机一次性验收

## 当前运行版本

- 模型：Stage 36 model-owner INT8 candidate，经 Stage 37 板端防误报策略保护；
- 类别：`silence / unknown / knock / alarm_clock / alarm_alert / baby_cry / glass_break / kettle`；
- 产品功能中 `glass_break` 已禁用，播放玻璃碎裂应显示未知且不得告警；
- 所有已确认告警都保持到串口屏“确认”键被按下，不自动消失。

## 测试前检查

1. 四个麦克风供电、BCLK、WS、四根 SD 线均已连接；L/R 拨码维持当前已验证配置。
2. WS2812、串口屏和马达模块与开发板共地。
3. 马达模块使用 5 V，IN 接当前已验证控制引脚。
4. 串口屏波特率 9600，页面停留在主页面。
5. 每次目标声音测试后，按“确认”等待恢复，再测试下一项。

## 建议顺序

## 通过标准

- 负样本 1–4 全程不得出现蓝/黄/红灯和马达动作；
- 目标声音 5–9 的类别、方向、灯带、马达在同一次事件中对应；
- 确认前类别/方向/灯带/马达保持，确认后全部清除；
- 屏幕在结果未确定时允许显示“识别中”，但不得展示上一次方向；
- 连续两次按确认不得造成下一次告警被提前清除。

## 已知边界

板端门槛能显著降低误报，但键盘和门锁与敲门都属于机械瞬态，最终模型仍应加入 Stage 38 的现场硬负样本重训。若某一负样本仍触发，请立即记录声音类型、发生次数、屏幕类别和灯带颜色，并采集同一条件的 `hardneg_*` 同步 PCM/PL 矩阵。
