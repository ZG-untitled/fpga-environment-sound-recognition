# Stage 38 现场硬负样本说明

## 目的

这些样本用于解决现场模型把以下声音误识别为 `knock` 或 `alarm_alert` 的问题：

- 正常敲键盘；
- 门把手、门锁卡扣的机械声；
- 正常开门、关门声；
- 普通房间背景噪声。

所有 `hardneg_*` 样本的训练标签都必须是 `unknown`，不能按文件中的瞬态冲击形状改标为 `knock`。

## 每条样本内容

- `*_ch0_pcm.csv`：与 PL 特征同一次采集的原始 ch0 PCM，共 15872 点；
- `*_pl_matrix.csv`：同一次采集的 49×40 PL 特征，共 1960 项；
- `analysis/`：窗口映射、频带统计和采集清单；
- `manifest.csv`：统一标签和负样本类型。

## 模型训练要求

1. 类别编号保持不变：`0 silence, 1 unknown, 2 knock, 3 alarm_clock, 4 alarm_alert, 5 baby_cry, 6 glass_break, 7 kettle`。
2. 将本包全部加入训练集的 `unknown` 类，并把同来源的相邻录音放在同一数据划分，避免数据泄漏。
3. 对 `knock` 与 `unknown` 增加混淆专项统计，单独报告键盘、门锁、开关门三组的误报率。
4. 保留真实敲门的召回率，不要只通过抬高阈值换取低误报。
5. 导出新的裸机 INT8 包、逐层黄金向量、输入量化参数和板端回归结果。
6. 验收目标：这些硬负样本不输出 `knock`/`alarm_alert`；真实敲门仍能稳定输出 `knock`。

## 当前板端临时保护

在模型重训前，板端已经增加：

- `knock` 置信度至少 220/255；
- 连续两次确认；
- PCM 冲击峰值、平均幅度、峰均比和持续帧数联合门控；
- `alarm_alert` 连续三次确认。

这些是安全兜底，不替代模型用硬负样本重训。
